Configuracao do Servidor MCP

Endpoint MCP

URL base do servidor MCP (Streamable HTTP):

{{BASE_URL}}/mcp

Autenticacao

O endpoint MCP em /mcp utiliza autenticacao via cabecalho X-API-Key (o mesmo mecanismo gerenciado pelo AuthMiddleware e verify_api_key).

O valor do cabecalho deve ser uma das chaves configuradas na variavel de ambiente TMPUP_API_KEYS no servidor.

Exemplo de Configuracao do Cliente MCP

Exemplo de configuracao de cliente MCP compativel com transporte HTTP:

{{JSON_CONFIG}}
O nome exato dos campos pode variar um pouco dependendo do cliente MCP usado.

Ferramentas MCP Disponiveis

Lista de ferramentas MCP implementadas no servidor:

upload_file Upload a file encoded in base64 with TTL in seconds (0 = never expires).
list_files List active (non-expired) files with metadata.
get_file_info Get metadata for a specific active file.
extend_ttl Extend or update TTL for an existing file.
delete_file Delete a file by ID.
