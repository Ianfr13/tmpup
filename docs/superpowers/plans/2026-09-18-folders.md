# Folders + media viewer Implementation Plan

> **For agentic workers:** small parallel slices after the foundation lands. TDD. No subfolders.

**Goal:** Virtual one-level folders (create, group files, zip upload/download via MCP+API+UI) and in-browser preview for image/video/audio/PDF.

**Architecture:** Optional `folder_id` on file sidecars; folders are `<uuid>.folder.json`. Zip extract flattens to basenames (zip-slip rejected). Download streams a zip (auth required). Files keep their own TTL/URLs. Deleting a folder deletes its files.

**Tech Stack:** Fastify, MCP SDK, fflate, Vitest, existing FileMetadata lock.

## Files

- Create: `src/folders.ts`, `src/routes/folders.ts`, `test/folders.test.ts`, `test/folder-routes.test.ts`
- Modify: `src/types.ts`, `src/storage.ts`, `src/files.ts`, `src/mcp.ts`, `src/routes/files.ts`, `src/routes/transfer.ts`, `src/server.ts`, `src/templates/{viewer,list,mcp-setup,index}.html/ts`, `README.md`, `test/{storage,templates,mcp,routes}.test.ts`

## Wave 1 — foundation (serial)

1. Types + `FileMetadata.folderId` + `previewKind` + `folder_id` on public dict.
2. `src/folders.ts`: create/list/get/delete, move, zip in/out, logs.
3. `test/folders.test.ts` covering zip-slip, collision all-or-nothing, destructive delete, root files untouched.

## Wave 2 — parallel after wave 1

- **REST:** `src/routes/folders.ts` + `?folder_id=` / `X-Folder-Id` / PATCH move.
- **MCP:** create/list/get/delete/upload_folder/download_folder; `upload_file`/`list_files` gain `folder_id`.
- **Viewer:** `/v/` HTML for image/video/audio/PDF; else 307.
- **UI:** folder cards, drill-in, Nova pasta, Baixar/Excluir (confirm), Ver on previewable types.

## Contracts

- Folder: `{ id, name, created_at, file_count, total_size_bytes, download_url }`
- File public dict gains `folder_id: string | null`
- Empty folder download → 400 `Folder is empty`
- Duplicate name → 409
- Zip: no `..`, no absolute path, basename only, in-zip or in-folder name collision → abort with no writes
- Auth: folder REST/MCP like `/api/files`; `/v/` `/d/` stay public
